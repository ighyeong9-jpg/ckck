# 20260226 마이그레이션 실행 순서

Supabase Dashboard → SQL Editor에서 아래 순서로 실행.

## 1단계: 테이블 생성
파일: `20260226_add_law_engine_tables.sql`

생성되는 테이블:
- `laws` (법령 마스터)
- `law_checks` (법령 체크 결과)
- `risk_scores` (리스크 점수 이력)
- `warranties` (하자담보)

추가되는 컬럼:
- `evidence_files.merkle_root`
- `evidence_files.ai_check_result`
- `evidence_files.is_evidence`

## 2단계: 시드 데이터 입력
파일: `20260226_seed_laws.sql`

삽입되는 데이터:
- 12개 법령 마스터 데이터 (laws 테이블)

## 완료 확인 쿼리
```sql
-- 테이블 생성 확인
SELECT table_name FROM information_schema.tables
WHERE table_schema = 'public'
  AND table_name IN ('laws','law_checks','risk_scores','warranties')
ORDER BY table_name;

-- 법령 데이터 확인
SELECT sort_order, code, name, article, risk_weight, category
FROM laws ORDER BY sort_order;
```

기대 결과:
- 테이블 4개 생성됨
- 법령 12개 (sort_order 1~12)
