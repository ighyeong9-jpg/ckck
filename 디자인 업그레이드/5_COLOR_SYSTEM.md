## PART 1. 전세계 대기업들이 색상을 정하는 원리

### 원칙 1: 색상은 감정이다 (Color = Emotion)

전세계 모든 성공한 웹/앱 디자인의 공통점:
색상이 먼저 감정을 만들고, 감정이 신뢰를 만들고, 신뢰가 결제를 만든다.

```
색상 → 감정 → 신뢰 → 행동 (결제/가입/클릭)
```

색상을 잘못 쓰면:
- 불신 → 이탈
- 불안 → 회피
- 혼란 → 포기

---

### 원칙 2: 업종별 색상 언어 (Industry Color Language)

각 업종은 색상으로 "나는 이런 사람입니다"를 전달한다.

**핀테크 / 금융:**
- 토스: 순백 + 파랑 → "투명하고 신뢰할 수 있습니다"
- 카카오페이: 노랑 → "친근하고 쉽습니다"
- 뱅크샐러드: 민트 → "건강한 돈 관리"
- Stripe: 인디고 그라데이션 → "개발자가 신뢰하는 인프라"

**법률 / 계약 / 공공:**
- 대한민국 법원: 네이비 + 골드 → "권위와 엄중함"
- LG U+: 마젠타 → "차별화된 통신"
- 삼성 SDS: 딥 블루 → "엔터프라이즈 신뢰"

**건설 / 안전 / 산업:**
- 안전 조끼: 형광 오렌지 → "위험 경고 + 현장 식별"
- 캐터필러(CAT): 노랑 + 검정 → "강력함 + 산업적"
- 삼성물산: 딥 블루 → "대형 건설의 신뢰"

**소비자 앱 / 라이프스타일:**
- 당근마켓: 오렌지 → "따뜻한 동네 거래"
- 쿠팡: 로켓 레드 → "빠름 + 할인"
- 오늘의집: 민트 그린 → "인테리어 청량감"

---

### 원칙 3: 3색 법칙 (60-30-10 Rule)

전 세계 최고 디자이너들이 따르는 불변의 법칙:

```
60% = 도미넌트 컬러 (배경, 화면의 지배색)
30% = 세컨더리 컬러 (섹션, 카드, 보조)
10% = 액센트 컬러  (CTA 버튼, 강조, 행동 유도)
```

토스: 60% 흰색 + 30% 연회색 + 10% 파랑
Apple: 60% 흰색/검정 + 30% 회색 + 10% 파랑
Stripe: 60% 흰/회색 + 30% 다크 + 10% 인디고

### 원칙 4: 신뢰와 전환의 색상 심리학

**파랑 계열** → 신뢰, 안전, 전문성
→ 은행, 병원, IT 기업이 사용
→ "이 회사는 안전합니다"

**오렌지/레드** → 긴급함, 행동, 에너지
→ CTA 버튼, 할인 배지, 경고
→ "지금 당장 하세요"

**초록** → 승인, 성공, 자연
→ GO 판정, 완료, 환경
→ "괜찮습니다, 통과했습니다"

**네이비 (딥 블루)** → 권위, 법적 신뢰, 엄중함
→ 법원, 계약서, 군/경찰, 대기업 B2B
→ "우리는 법적으로 당신을 보호합니다"

**흰색** → 투명함, 청결, 숨김 없음
→ 현대 SaaS, 핀테크
→ "우리는 숨기는 게 없습니다"

### 원칙 5: 왜 대기업 앱은 성공하는가

1. **색상 일관성** — 어떤 페이지에서도 같은 색상 경험
2. **감정 설계** — 화면을 열었을 때 느끼는 감정까지 설계
3. **행동 유도** — 어디를 눌러야 하는지 색상으로 명확하게
4. **브랜드 각인** — 색상만 봐도 "아 거기"가 되는 것

토스를 쓰는 이유: 흰 배경 + 파랑 버튼 = 깔끔하고 안전한 느낌
카카오를 쓰는 이유: 노랑 = 친근하고 쉬운 느낌
체키를 써야 하는 이유: (아래 참조)

## PART 2. 체키 시그니처 컬러 설계 근거

### 체키 사용자의 감정 여정

```
공사 시작 전:  불안 (얼마 들지? 바가지 아닐까?)
공사 중:       긴장 (잘 되고 있는 건가? 이슈가 생겼다)
분쟁 발생:     공포 (700만원 날릴 것 같다)
체키 사용 후:  안도 (기록이 있다. 증거가 있다)
해결:          신뢰 (다음에도 체키 쓰겠다)
```

**체키가 해야 할 것:**
불안한 사람이 화면을 열었을 때 즉시 "여기는 안전하다"는 느낌을 줘야 한다.
동시에 "이건 진지하고 법적으로 강력한 시스템이다"는 권위도 줘야 한다.

---

### 체키 시그니처 컬러: AUTHORITY NAVY + SITE ORANGE

**선택 근거:**

```
딥 네이비 (#0F2744)  = 법원의 색 + 계약서의 색 + 법적 권위
                      "체키는 당신을 법적으로 보호합니다"

공사 오렌지 (#E8651A) = 안전 조끼의 색 + 현장의 색 + 행동 촉구
                      "이건 현장 전문가가 만든 시스템입니다"
```

이 두 색이 합쳐지면:

```
네이비 + 오렌지 = 법적 권위 + 현장 전문성
               = 변호사 + 현장 소장
               = 당신을 법적으로 AND 현장에서 모두 보호하는 시스템
```

**경쟁 제품과 차별화:**
- 오늘의집: 민트 (인테리어 감성) → 분쟁 보호 느낌 없음
- 직방: 파랑 (부동산 플랫폼) → 공사 관리 느낌 없음
- 카카오홈: 노랑 (친근함) → 법적 권위 없음
- 체키: 네이비 + 오렌지 → 유일한 포지션

### Primary Palette

```css
/* ━━━ CORE ━━━ */
--checkin-navy:       #0F2744;   /* 딥 네이비 — 브랜드 주색, 법적 권위 */
--checkin-navy-mid:   #1A3A5C;   /* 미드 네이비 — 카드 배경, 섹션 */
--checkin-navy-light: #1E4976;   /* 라이트 네이비 — hover, 선택 상태 */

--checkin-orange:     #E8651A;   /* 사이트 오렌지 — CTA, 액션, 현장 */
--checkin-orange-hot: #FF7020;   /* 핫 오렌지 — hover 상태 */
--checkin-orange-soft:#FFF3ED;   /* 소프트 오렌지 — 알림 배경 */

/* ━━━ SEMANTIC ━━━ */

--checkin-warn:       #F59E0B;   /* 경고 — 앰버 (주의, 확인 필요) */
--checkin-info:       #3B82F6;   /* 정보 — 파랑 (안내, 알림) */

/* ━━━ SURFACE (배경/카드) ━━━ */
--bg-primary:         #FFFFFF;   /* 주 배경 — 순백 (투명함) */
--bg-secondary:       #F8FAFC;   /* 보조 배경 — 냉백색 */
--bg-tertiary:        #F1F5F9;   /* 3차 배경 — 섹션 구분 */
--bg-dark:            #0A1929;   /* 다크 배경 — 히어로, 헤더 */
--bg-dark-card:       #0F2744;   /* 다크 카드 — 네이비 기반 */

/* ━━━ TEXT ━━━ */
--text-primary:       #0F172A;   /* 주 텍스트 — 거의 검정 */
--text-secondary:     #475569;   /* 보조 텍스트 — 슬레이트 */
--text-muted:         #94A3B8;   /* 흐린 텍스트 — 힌트, 레이블 */
--text-on-dark:       #F8FAFC;   /* 다크 배경 위 텍스트 */

/* ━━━ BORDER ━━━ */
--border-light:       #E2E8F0;   /* 라이트 보더 */
--border-mid:         #CBD5E1;   /* 미드 보더 */
--border-navy:        rgba(255,255,255,0.08); /* 네이비 위 보더 */
```

### 사용 원칙

```
히어로/헤더 배경:    --bg-dark (#0A1929) + 네이비 그라데이션
카드/섹션 배경:      --bg-primary (#FFFFFF) 또는 --bg-secondary
주요 CTA 버튼:       --checkin-orange (#E8651A)
보조 버튼:           --checkin-navy border + navy text
GO 판정 배지:        --checkin-go (#10B981)
NO-GO 판정:          --checkin-nogo (#EF4444)
분쟁 경고:           --checkin-nogo 배경 + 700만원 프레임

## PART 4. 페이지별 적용 기준

### 랜딩페이지 (marketing/page.tsx)
```
배경: #0A1929 (다크 네이비) — "진지하고 강력한 시스템"
히어로 텍스트: 흰색 + 오렌지 강조
CTA 버튼: --checkin-orange + shadow-cta
섹션 구분: #FFFFFF 카드 on 다크 배경
효과: 미묘한 그리드 패턴 오버레이 (건설 도면 느낌)
```

### 로그인 페이지 (auth/page.tsx)
```
배경: #0A1929 → #0F2744 그라데이션
카드: #FFFFFF + shadow-xl (부유하는 느낌)
로고: 네이비 배경 위 흰색 체키
입력창: --bg-secondary + --border-light
버튼: --checkin-orange (로그인은 행동 = 오렌지)
```

### 대시보드 (dashboard/page.tsx)
```
배경: --bg-secondary (#F8FAFC) — "클린하고 전문적"
사이드바: --checkin-navy (#0F2744) — "권위"
카드: --bg-primary (#FFFFFF) + shadow-sm
KPI 숫자: --checkin-navy (강조)
리스크 알림: --checkin-nogo 배경
GO 배지: --checkin-go
CTA: --checkin-orange
```

### 체크리스트/진단 페이지
```
