CHECK-IN 체키 — COLOR SYSTEM UPGRADE PROMPT v1.0
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

체키의 전체 색상 시스템을 업그레이드한다.
이 파일을 읽고 아래 순서대로 정확하게 실행해라.

━━━ 0. 색상 철학 (반드시 이해하고 시작해라) ━━━

체키는 두 가지를 동시에 전달해야 한다:
1. "이건 법적으로 강력한 시스템이다" → 딥 네이비 (#0F2744)
2. "지금 당장 행동해야 한다" → 공사 오렌지 (#E8651A)

사용자는 공사 분쟁으로 불안한 상태에서 진입한다.
배경색이 먼저 "여기는 안전하고 권위 있다"는 신뢰를 줘야 한다.
그다음 오렌지 CTA가 행동을 유도한다.

전환 흐름:
빨간 경고(공포) → 네이비(권위/안심) → 오렌지 CTA(결제)

━━━ 전체 공통 적용 규칙 ━━━

버튼 시스템:
PRIMARY = var(--checkin-orange) + shadow-cta + 흰 텍스트
SECONDARY = var(--checkin-navy) border + navy 텍스트
DANGER = var(--checkin-nogo) + 흰 텍스트
SUCCESS = var(--checkin-go) + 흰 텍스트
GHOST = transparent + border-light + text-primary

폰트: Pretendard 우선 (없으면 Apple SD Gothic Neo 폰트)
헤딩 font-weight: 800 또는 900
본문 font-weight: 400~500
강조 font-weight: 700

애니메이션:
transition: all 0.2s ease (버튼 hover)
transition: all 0.3s ease (카드 hover)
없이는 색상 변환에 0.15s 이상 사용

접근성:
모든 텍스트 WCAG AA 기준 (4.5:1 명암비)
오렌지 위 흰 텍스트 ← OK
네이비 위 흰 텍스트 ← OK
흰 배경 위 navy 텍스트 ← OK

━━━ 금지 ━━━

❌ 기존 회색 배경(#f5f5f5 계열) 그대로 유지
❌ 파란색 계열 CTA 버튼 (토스 파랑으로 대체하지 말 것)
❌ 보라색 사용 (체키 아이덴티티 아님)
❌ 흰색 배경에 흰색 카드 (구분 불가)
❌ 색상 변수 하드코딩 (반드시 var(--변수명) 사용)
