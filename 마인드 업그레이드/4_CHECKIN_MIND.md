## 너는 지금 무엇을 만들고 있는가

인테리어 공사는 100% 사람이 하는 일이다.
사람이 하는 일이라 변수가 무한하다.
실수, 감정, 기억 차이, 이해충돌이 반드시 생긴다.

이 변수들이 쌓이면 분쟁이 된다.
분쟁 1건당 평균 700만원.
한국에서 매년 수십만 건.

체키는 이 분쟁을 막는 시스템이다.

---

## 분쟁이 생기는 진짜 이유 5가지

```
기억이 다르다     → "그랬는데요" vs "안 그랬는데요"
기록이 없다       → 카톡/전화/구두 → 나중에 증거 없음
정보가 늦다       → 바빠서 못 봄 → "왜 몰랐어요?"
범위가 불명확하다 → "당연히 포함인 줄"
감정이 앞선다     → 작은 오해 → 큰 싸움
```

체키는 이 5가지를 전부 차단한다.
변수를 없애는 게 아니다.
변수가 생겼을 때 빠르고 정확하게 처리하는 것이다.

---

## 사용자가 하는 것 (딱 3가지)

```
말하거나  →  사진 찍거나  →  [확인] 누르거나
```

**나머지는 체키가 전부 한다.**

예산 감잡기      → 말하면 30초 안에 예산 가이드
사진 품질 판단   → 찍어 올리면 GO/NO-GO 자동 판정
업체 감시        → 분쟁 징후 자동 감지
이슈 소통        → 현장 변수 자동 분류 + 승인 처리
증거 보관        → 체키 쓰면 자동으로 증거 생성
하자 추적        → 만료 30일 전 자동 알림
법적 대응        → 상황 보고 법조문 + 내용증명 자동

## 모든 기능에 적용할 판단 기준

기능을 만들기 전에 반드시 이 질문을 해라:

```
"이 기능이 분쟁을 예방하는가?"
"이 기능이 분쟁을 해결하는가?"
"이 기능이 증거를 만드는가?"

하나라도 YES → 구현
전부 NO      → 다시 생각
```

## 체키의 말투 원칙

체키는 전문가처럼 알지만 친구처럼 말한다.

```
❌ "민법 제667조에 의거하여 수급인은 하자담보책임을..."
✅ "업체가 하자 보수 안 해준다고요?
    법적으로 요청할 권리 있어요 💪
    내용증명 양식 만들어드릴까요?"
```

규칙:
- 한 문장 20자 이내
- 이모지 1~2개
- 행동 먼저, 법조문 뒤
- 카카오처럼 친근하게
- 거부감 없이

## 인간 vs AI 역할 분리

```
인간이 하는 것 (판단 + 결정 + 책임):
  → 업종/규모 선택
  → 견적 승인
  → 체크리스트 최종 확인 (현장 육안)
  → 변경 승인
  → 합의서 서명
  → 최종 리포트 승인

AI가 하는 것 (나머지 전부):
  → 프로젝트 자동 세팅
  → 견적서 자동 생성
  → 체크리스트 자동 완성 (사진 1장으로)
  → 비용 자동 분석
  → 변경 자동 기록
  → 증거 자동 패키징 (SHA-256 + Merkle Tree)
  → 리포트 자동 생성
  → 리스크 자동 감지
  → 하자담보 만료 자동 알림
  → 분쟁 징후 자동 감지
  → 관련 판례 자동 제시
```

**[확인] 버튼을 누른 사람에게 법적 책임이 귀속된다.**
이것이 체키의 핵심 메커니즘이다.

## 이 시스템이 세계 최초인 이유

한국에만 있는 3가지가 겹쳐야 이 시스템이 가능하다:

1. **중대재해처벌법** — 건설 현장 안전 처벌 강화
2. **다단계 하도급 구조** — 원청→하도급→재하도급 복잡한 책임 관계
3. **인테리어 분쟁 급증** — 연간 수십만 건, 평균 700만원 피해

이 세 가지를 동시에 처리하는 AI 시스템은 전 세계에 없다.
특허 3건이 이것을 보호한다.

## 결제 전환 원칙 (공포→안심→결제)

```
리스크 점수 61점+
    ↓
"이 리스크를 방치하면 분쟁 비용 평균 700만원"  (공포)
    ↓
"체키가 모든 기록을 증거로 만들어드립니다"     (안심)
    ↓
[증빙 PDF 받기 → 99,000원]                    (결제)
```

손실 프레임이 이익 프레임보다 2배 강하다.
미확인 항목 = 잠재 분쟁 비용으로 프레임한다.

## Claude Code 작업 원칙

```
1. 파악 후 보고 먼저. 보고 전 코드 건드리지 말 것.
2. 기존 코드/기능 절대 수정 금지. 신규 추가만.
3. 모든 AI 호출은 brain.ts 통해서만.
4. 각 순위 완료 시 "✅ X순위 완료 → Y순위 시작" 보고.
5. npm 패키지 설치 전 반드시 확인 요청.
6. DB 마이그레이션은 scripts/migration.sql에 추가.
7. 완료 후 반드시 npm run check 실행.
8. develop 커밋 → main 머지 → push 순서 준수.
9. 완료 전까지 멈추지 않는다.
```
