# AI 브레인(체키) 가이드

## 아키텍처
```
사용자 요청
    ↓
brain.ts (단일 진입점)
    ↓
┌─────────────┐    실패 시    ┌──────────────┐
│ Gemini 1차  │ ──────────→ │ Claude 폴백  │
└─────────────┘              └──────────────┘
    ↓
응답 반환
```

## brain.ts 기능
1. **AI 채팅**: 건설/안전 관련 자유 질문 응답
2. **법규 확인**: 12개 법규 기반 자동 확인 점검
3. **리스크 분석**: 특허 공식으로 리스크 예측
4. **인증서 발급**: 4항목×25점=100점 AI 검증
5. **리포트 생성**: 현장 현황 자동 요약
6. **이슈 분류**: 현장 이슈 자동 카테고리 분류
7. **견적 분석**: 견적서 적정성 AI 분석
8. **사전 알림**: 위험 징후 사전 알림

## API 엔드포인트
| 엔드포인트 | 용도 |
|-----------|------|
| `/api/ai/chat` | 자유 채팅 |
| `/api/ai/check` | 법규 확인 |
| `/api/ai/predict` | 리스크 예측 |
| `/api/ai/report` | 리포트 생성 |
| `/api/ai/classify-issue` | 이슈 분류 |
| `/api/ai/quote-analyze` | 견적 분석 |
| `/api/ai/proactive` | 사전 알림 |
| `/api/ai/notebook` | AI 노트북 |

## 프롬프트 전략
- 시스템 프롬프트: 건설 안전 전문가 페르소나
- 법규 데이터: 12개 법규 조항 임베딩
- 체크리스트: 60개 항목 컨텍스트 주입
- 응답 형식: 구조화된 JSON (프론트 파싱용)
