# 오프라인 모드 사양서

## 개요
지하, 산간, 통신 불가 현장에서도 체키의 핵심 기능을 사용할 수 있습니다.

## 오프라인 지원 기능
| 기능 | 오프라인 | 동기화 방식 |
|------|----------|------------|
| TBM 체크리스트 | ✅ | 큐 → 자동 동기화 |
| QR 출역 체크인 | ✅ | 큐 → 자동 동기화 |
| 사진 촬영/저장 | ✅ | 백그라운드 업로드 |
| 체크리스트 조회 | ✅ | 캐시 사용 |
| AI 채팅 | ❌ | 온라인 필수 |
| PDF 리포트 | ❌ | 온라인 필수 |

## 기술 스택
- **Service Worker**: Next.js PWA (next-pwa)
- **로컬 저장소**: IndexedDB (idb 라이브러리)
- **동기화 큐**: Background Sync API
- **캐시 전략**: Cache First (정적), Network First (동적)

## 동기화 프로세스
1. 오프라인 작업 → IndexedDB `pending_sync` 테이블에 저장
2. 네트워크 감지 (`navigator.onLine` + `online` 이벤트)
3. 큐 순서대로 Supabase API 호출
4. 성공 시 `pending_sync`에서 제거
5. 실패 시 재시도 (최대 5회, 지수 백오프)

## 충돌 해결
- 타임스탬프 기준 Last-Write-Wins
- 충돌 발생 시 알림 배너 표시
- 수동 병합 UI 제공 (향후)

## 용량 제한
- IndexedDB: 기기 저장소의 50% (브라우저 정책)
- 오프라인 사진: 최대 50장 (압축 후 약 250MB)
- 캐시: 최근 7일 데이터
