# 경쟁사 3사 심층 분석

## 세이프로 (노버스메이)
- 40만+ 고객, 시장 1위
- 1인 5000원/월 (30인=15만원)
- 15개 언어, AI 위험성평가, 조달청 등록
- 약점: 기능 과부하, 초기세팅 복잡, 건설특화 부족, 오프라인 없음, CS지연

## 스마플 (산업안전협회+LGU+)
- 협회 공식 솔루션 (공신력)
- Active User 100명 최소 35만원/월
- 약점: 소규모에 가격 과도, 기능 미완성, 다국어 없음, 2023년 출시

## 무사퇴근 (공인노무사)
- 법적 안전성 최우선
- 30인 약 9만원/월
- AI 위험성평가 70% 시간절감, 카카오 알림톡
- 약점: 건설특화 없음, 출역관리 없음, 오프라인 없음

## 3사 공통 약점 = Check-In 기회
1. 건설 공종 특화 DB 없음 (전부 범용)
2. 현장 출역 체크인 없음 (QR/NFC)
3. 오프라인 모드 없음
