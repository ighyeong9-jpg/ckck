# Check-In 파일럿 운영 계획서 (5개사 무료 테스트)

> **목적**: 5개 사업장을 대상으로 Check-In을 무료 파일럿 운영하며, 수집 피드백으로 제품·운영 개선

---

## 1. 파일럿 개요

| 항목 | 내용 |
|------|------|
| 대상 | 5개사 (인테리어·건설 현장 또는 유사 업종) |
| 기간 | 예: 4~8주 (운영 정책에 따라 조정) |
| 조건 | 무료 사용, 사용 피드백·간단한 설문 참여 |
| 목표 | 실제 사용 패턴 파악, 사전점검·변경·하자 기록 활용도 검증, UI/역할별 불편 사항 수집 |

---

## 2. 5개사 선정 시나리오

다음과 같이 5개 유형을 한 곳씩 두어 다양한 사용 시나리오를 커버하는 것을 권장합니다.

| 순번 | 유형 | 예시 | 기대 시나리오 |
|------|------|------|----------------|
| 1 | 소규모 인테리어 (카페·소매) | 카페 1곳, 소규모 리모델링 | 현장소장 1인, 사전점검·하자 위주 사용 |
| 2 | 중규모 인테리어 (음식점·사무실) | 음식점 1곳, 2~3개월 공사 | 현장소장 + 작업반장, 변경·하자 빈번 |
| 3 | 건축주 직접 관리 | 건축주가 시공사·하도급과 함께 사용 | 건축주·시공사·감리 역할 모두 활용 |
| 4 | 하도급 참여 현장 | 원도급 하에 1개 현장 참여 | 하도급 관점 변경·하자·사전점검 기록 |
| 5 | 건물관리자 연계 | 빌딩/단지 내 인테리어 공사 | 건물관리자 확인·공용부·안전 항목 검토 |

- 선정 시: **현장소장·건축주** 중 실제로 “기록·기록 관리 예방” 수요가 있는 곳을 우선하는 것이 유리합니다.
- 5개사가 모두 다른 업종·규모가 아니어도 되며, 위는 “다양한 역할·규모”를 한 번에 테스트하기 위한 예시입니다.

---

## 3. 무료 테스트 시나리오 (공통)

파일럿 참여사에는 아래 시나리오를 안내하고, 가능한 범위에서 수행하도록 요청합니다.

### 3.1 온보딩 (1주)

- [ ] 계정 생성(회원가입) 및 로그인
- [ ] 테스트용 또는 실제 **프로젝트 1개 생성** (이름, 발주처, 금액, 일정 등)
- [ ] **대시보드**에서 프로젝트 수·상태 확인
- [ ] **프로젝트 상세**에서 발주처, 금액, 주소, 일정, 진행률, 최근 활동 확인

### 3.2 사전점검 (1~2주)

- [ ] **사전점검** 탭 진입, 항목별 완료 여부·완료율 확인
- [ ] 실제 현장 기준으로 **최소 5개 항목** 체크·완료일 기록 (가능 시 증빙 사진)
- [ ] “항목 추가” 등 추가 기능이 있다면 1~2건 사용 후 불편 사항 기록

### 3.3 변경·하자 (2~4주)

- [ ] **변경사항** 탭에서 “변경 요청” 1건 이상 등록 (제목, 사유, 금액 영향)
- [ ] **하자관리** 탭에서 하자 1건 이상 등록 (제목, 위치, 심각도, 설명, 가능 시 사진)
- [ ] 변경 승인대기·하자 미해결/처리중 상태를 실제 흐름에 맞게 한 번 이상 업데이트 (기능 지원 시)

### 3.4 역할별 확인 (전 기간)

- [ ] **현장소장**: 위 전체 흐름 수행, 대시보드·프로젝트 상세를 주 1회 이상 확인
- [ ] **작업반장/안전관리자**: 사전점검·하자 등록·확인 위주 사용
- [ ] **건축주/감리/건물관리자**: 조회 위주로 진행률·변경·하자 확인 (역할이 참여사에 있는 경우)

---

## 4. 피드백·모니터링

- **설문**: 파일럿 중간(2~4주), 종료 시 각 1회 — 사용 빈도, 유용한 기능, 불편한 점, 역할별 요구 사항
- **정량**: 로그인 횟수, 프로젝트 수, 사전점검 완료 항목 수, 변경 건수, 하자 건수 (Supabase·분석 도구로 집계 가능 시)
- **정성**: “어떤 화면을 가장 많이 썼는지”, “어떤 기록이 실제로 기록 관리/검수에 도움이 되었는지” 인터뷰 또는 서술형 설문

---

## 5. 성공 기준 (예시)

- 5개사 모두 **최소 1개 프로젝트 생성 + 사전점검 5항목 이상** 사용
- 5개사 중 **3개사 이상**에서 변경 또는 하자 **각 1건 이상** 등록
- **역할별 사용자 가이드** 기반으로 현장소장·작업반장·건축주 등 최소 2가지 역할이 실제로 사용
- 종료 설문에서 “다음에도 사용할 의향” 또는 “실무에 도움됨” 항목이 일정 비율 이상 (예: 60% 이상)

---

## 6. 리스크·대응

| 리스크 | 대응 |
|--------|------|
| 참여사가 바쁘다 | 최소 시나리오만(프로젝트 1개 + 사전점검 5항목)으로 부담 축소 |
| 역할이 1인뿐이다 | 1인이라도 “현장소장 + 작업반장” 관점으로 사전점검·변경·하자 모두 체험하도록 안내 |
| 기술 오류·불편 | 지원 채널(이메일/채팅) 명시, 로그·스크린샷 수집 후 개선 반영 |
