# 체크인 35점 → 50점: 사용자 전체 여정 UI 완성

> 목표: 한 명의 사용자가 회원가입부터 증거 패키지 다운로드까지 끊김 없이 사용할 수 있는 상태.
> 이게 끝나면 베타 테스트 10곳을 돌릴 수 있다.
> 프롬프트 1 → 2 → 3 → 4 → 5 순서. 한 번에 전부 실행. 중간에 멈추지 말고 끝까지.
> 모든 작업 전 docs/ 루트의 설계 문서 5개를 참조할 것.

---

## 프롬프트 1: 프로젝트 생성 → 체크리스트 자동 생성 플로우 완성

```
사용자가 현장(프로젝트)을 처음 등록하고 체크리스트가 자동 생성되는 전체 플로우를 완성해줘.
docs/BUILDER_SPEC.md의 모듈 2(프로젝트 관리), 모듈 3(체크리스트)를 참조.

====================================
A. 프로젝트 생성 페이지 (/projects/new)
====================================

입력 필드:
- 현장명 (필수) — 예: "강남 카페 인테리어"
- 업종 선택 (필수) — 드롭다운: 카페/식당, 주거(아파트/빌라/주택), 사무실, 매장/상업, 공장/창고, 기타
  - 업종 선택 시 아이콘 + 간단한 설명 표시
  - 이 선택이 체크리스트 자동 생성 + 소방 체크리스트 업종별 추가를 결정함
- 현장 주소 (필수) — 텍스트 입력 (향후 주소 검색 API 연동 예정)
- 예상 공사비 (선택) — 숫자 입력, 단위: 만원
- 공사 시작일 (선택) — 날짜 선택
- 공사 예정 완료일 (선택) — 날짜 선택
- 현장 설명 (선택) — 텍스트 영역

UI:
- 단계별 폼이 아니라 한 페이지에 전부 표시 (심플하게)
- 필수 필드만 채우면 "현장 등록" 버튼 활성화
- 버튼 클릭 → 로딩 → 프로젝트 생성 + 체크리스트 자동 생성 + 소방 체크리스트 자동 생성
- 완료 후 /projects/:id 페이지로 자동 이동

====================================
B. 체크리스트 자동 생성 로직 확인/보완
====================================

프로젝트 생성 시 자동으로:
1. 업종별 일반 체크리스트 생성 (기존 43개 업종 데이터 활용)
2. 소방 공통 체크리스트 생성 (NFSC 기반, 모든 업종 공통)
3. 소방 업종별 추가 체크리스트 생성 (업종에 따라)
4. 17개 법령 체크 초기 실행 (전부 pending 또는 첫 판정)
5. 리스크 점수 초기 계산

이 5단계가 프로젝트 생성 직후 자동으로 실행되는지 확인하고, 안 되면 구현.

====================================
C. 프로젝트 목록 페이지 (/projects)
====================================

내 프로젝트 전체 목록:
- 카드형 레이아웃
- 각 카드: 현장명, 업종 아이콘, 리스크 점수(등급 색상), 공정률 바, 법령 미충족 수
- 리스크 등급 배지: 안심(초록)/주의(노랑)/경고(주황)/위험(빨강)
- 소방 미충족 시 🔥 아이콘
- "새 현장 등록" 버튼 → /projects/new

프로젝트 없을 때:
- 빈 상태 화면: "아직 등록된 현장이 없습니다." + "첫 현장 등록하기" 버튼

완료 후 docs/BUILDER_SPEC.md 관련 기능 상태 업데이트.
```

## 프롬프트 2: 프로젝트 상세 + 체크리스트 작성 UI 완성

```
프로젝트 상세 페이지에서 체크리스트를 실제로 작성하고, 결과가 리스크 점수에 반영되는 전체 UI를 완성해줘.
docs/BUILDER_SPEC.md 모듈 2, 3, 5, 6, 11을 참조.

====================================
A. 프로젝트 상세 페이지 (/projects/:id)
====================================

탭 구조:
1. 개요 (기본 탭)
2. 체크리스트
3. 사진/증거
4. 법령 현황
5. 🔥 소방 안전
6. 하자담보

### 개요 탭:
상단 카드 3개:
- 리스크 점수 게이지 (0~100, 등급 색상, 등급 한글 라벨 + 메시지)
- 체크리스트 진행률 (완료/전체, 프로그레스 바)
- 법령 준수 현황 (충족 N / 미충족 N / 확인필요 N)

중단:
- 프로젝트 기본 정보 (현장명, 업종, 주소, 예산, 기간)
- "정보 수정" 버튼

하단:
- 최근 활동 타임라인 (체크리스트 체크, 사진 업로드, 법령 체크 등 — 데이터 있는 만큼만)
- "법령 재점검" 버튼 → 17개 법령 전체 재체크 + 리스크 재계산

====================================
B. 체크리스트 탭 (/projects/:id → 체크리스트 탭)
====================================

좌측: 카테고리 사이드바
- 공종별 카테고리 목록 (방수, 타일, 전기, 도배, 목공, 설비, 소방 등)
- 각 카테고리 옆에 완료율 표시 (예: "방수 3/8")
- 소방 카테고리는 🔥 아이콘 + 별도 강조

우측: 체크리스트 항목
- 선택한 카테고리의 항목 리스트
- 각 항목: 체크박스 + 항목명 + 법적 근거(있으면, 작은 글씨)
- 체크 시:
  1. 즉시 DB 업데이트
  2. 체크리스트 완료율 재계산
  3. 리스크 점수 재계산 (백그라운드)
  4. 개요 탭의 게이지 + 점수 자동 갱신
- 항목 옆에 📷 버튼 → 사진 연결 (사진 탭으로 이동 또는 인라인 업로드)
- 소방 항목에서 사진 없이 체크 시 노란 경고 배지: "증빙 사진 권장"

상단: 전체 진행률 바 + 완료 항목 수 / 전체 항목 수

필터:
- 전체 / 미완료만 / 완료만
- 필수만 / 선택 포함

====================================
C. 리스크 실시간 반영
====================================

체크리스트 체크할 때마다:
1. 해당 항목 DB 업데이트
2. 체크리스트 completion_rate 재계산
3. 법령 룰 엔진 재실행 (변경된 카테고리 관련 법령만)
4. 리스크 점수 재계산
5. 개요 탭 게이지, 프로젝트 카드 점수 실시간 반영

이 과정이 사용자 체감 1~2초 이내에 완료되어야 함.
무거우면 debounce 적용 (마지막 체크 후 1초 뒤 일괄 계산).

완료 후 docs/BUILDER_SPEC.md 관련 기능 상태 업데이트.
```

## 프롬프트 3: 사진 업로드 + 증거 관리 UI 완성

```
사진 업로드부터 SHA-256 해시 생성, 증거 지정, Merkle Tree까지 사용자가 직접 사용할 수 있는 UI를 완성해줘.
docs/BUILDER_SPEC.md 모듈 4, docs/BUSINESS_LOGIC.md 증거 관련 섹션 참조.

====================================
A. 사진/증거 탭 (/projects/:id → 사진/증거 탭)
====================================

상단:
- "사진 업로드" 버튼 (다중 선택 가능)
- 드래그 앤 드롭 영역: "사진을 여기에 끌어다 놓으세요"
- 업로드 중 프로그레스 바

업로드 시 자동 처리 (사용자에게 상태 표시):
1. ✅ 파일 업로드 완료
2. ✅ SHA-256 해시 생성 완료 (해시값 일부 표시: "a3f2b1...c8d4")
3. ✅ 메타데이터 추출 (GPS, 촬영시간)
4. ✅ 썸네일 생성

이 4단계가 순서대로 체크되는 진행 상태 표시.

갤러리 뷰:
- 격자형 썸네일 목록
- 각 사진에 표시: 촬영일시, 해시 아이콘(✅ 생성됨), 증거 배지(지정 시)
- 사진 클릭 → 상세 모달

====================================
B. 사진 상세 모달
====================================

좌측: 사진 원본 크게
우측: 메타데이터 정보
- 촬영 일시
- GPS 위치 (위도/경도, 가능하면 지도 미니맵)
- 촬영 기기
- 파일 크기
- SHA-256 해시값 (전체 64자, 복사 버튼)
- Merkle Tree 포함 여부

하단 버튼:
- "법정 증거로 지정" 토글 → is_evidence = true, 파란 배지 표시
- "체크리스트 연결" → 어떤 체크리스트 항목의 증거인지 연결
- "무결성 검증" 버튼 → SHA-256 재계산해서 DB값과 비교 → 일치/불일치 표시
- "삭제"

====================================
C. 증거 현황 섹션
====================================

사진/증거 탭 하단에:
- 전체 사진 N장 / 법정 증거 지정 N장 / 해시 생성 N장
- Merkle Tree 상태: "생성됨 (루트: a3f2...)" 또는 "미생성"
- "Merkle Tree 생성/갱신" 버튼 → 증거 지정된 사진으로 트리 생성
- "전체 증거 무결성 검증" 버튼 → 모든 증거 해시 재검증

====================================
D. 사진 카테고리 분류
====================================

업로드 시 또는 업로드 후:
- 카테고리 선택: 방수/타일/전기/자재/안전/소방/기타
- 카테고리별 필터링 가능
- 카테고리가 법령 체크에 영향 (자재 사진 없으면 민법 580조 violated 등)

완료 후 docs/BUILDER_SPEC.md 관련 기능 상태 업데이트.
```

## 프롬프트 4: 하자담보 관리 + 법령 현황 UI 완성

```
하자담보 자동 등록/관리 UI와 법령 현황 UI를 완성해줘.
docs/BUILDER_SPEC.md 모듈 6, 7, docs/BUSINESS_LOGIC.md 하자담보/법령 섹션 참조.

====================================
A. 법령 현황 탭 (/projects/:id → 법령 현황 탭)
====================================

상단 요약:
- 전체 17개 법령 중: 충족 N / 미충족 N / 해당없음 N / 확인필요 N
- 원형 차트 또는 도넛 차트로 시각화

법령 카드 리스트:
- 건설 법령 12개 + 소방 법령 5개
- 소방 법령은 별도 섹션으로 분리, 🔥 아이콘
- 각 카드: 법령명 + 조문 + 상태 아이콘 + 상태 메시지
  - ✅ 충족 (초록): "법령 요건이 충족되었습니다."
  - ⚠️ 미충족 (빨강): violation_action 메시지 + "권장 조치 보기" 펼침
  - ➖ 해당없음 (회색): "이 프로젝트에는 적용되지 않습니다."
  - 🔍 확인필요 (노랑): "수동 확인이 필요합니다."

미충족 카드 클릭 시 펼쳐지는 상세:
- 왜 미충족인지 구체적 사유 (details JSON에서)
- 권장 조치
- 관련 체크리스트 바로가기 링크
- 관련 사진 바로가기 링크

"전체 법령 재점검" 버튼 → 17개 법령 전체 재실행 → 결과 갱신

====================================
B. 하자담보 탭 (/projects/:id → 하자담보 탭)
====================================

상단 안내:
"공사 완료 후 공종별 하자담보기간이 자동으로 등록됩니다."
프로젝트 상태가 completed가 아니면 → "공사 완료 처리 후 하자담보가 자동 등록됩니다." + "공사 완료 처리" 버튼

"공사 완료 처리" 클릭 시:
1. 프로젝트 status를 completed로 변경
2. actual_end_date를 오늘로 설정
3. 공종별 하자담보 자동 생성 (BUSINESS_LOGIC.md의 공종별 기간 표 참조)
4. 각 하자담보의 end_date = actual_end_date + duration_years
5. 관련 법령 재체크

하자담보 목록 (completed 상태일 때):
- 공종별 카드: 공종명, 담보기간(N년), 시작일, 만료일, 남은 일수
- 상태별 색상:
  - 활성(active): 초록 — "담보 기간 중"
  - 만료임박(expiring_soon, 30일 이내): 주황 — "N일 후 만료"
  - 만료(expired): 빨강 — "담보 기간 만료"
- 타임라인 시각화: 가로 바 형태로 전체 담보기간 중 현재 위치 표시

하단:
- "하자담보 현황 내보내기" 버튼 (향후 PDF 연동 예정, 지금은 placeholder)

====================================
C. 공사 완료 처리 시 자동 생성되는 하자담보 목록
====================================

docs/BUSINESS_LOGIC.md의 공종별 담보기간 기준:
- 수장공사 (도배, 타일): 1년
- 도장공사: 1년
- 석공사: 1년
- 창호공사: 1년
- 방수공사: 3년
- 전기/통신공사: 2년
- 설비공사: 2년
- 옥외급배수/위생: 2년
- 조경공사: 2년
- 철근콘크리트공사: 5년
- 철골공사: 5년
- 대지조성공사: 2년

프로젝트의 체크리스트에 존재하는 공종만 하자담보 자동 생성.
예: 카페 인테리어면 방수, 타일, 전기, 도배, 설비 → 5개 하자담보 생성.

완료 후 docs/BUILDER_SPEC.md 관련 기능 상태 업데이트.
```

## 프롬프트 5: 대시보드 종합 + 증거 패키지 PDF + 전체 연결 점검

```
대시보드를 실전용으로 완성하고, 증거 패키지 PDF 기본 생성을 구현하고, 전체 사용자 여정을 점검해줘.
docs/BUILDER_SPEC.md 모듈 8, 11을 참조.

====================================
A. 대시보드 (/dashboard) 종합 완성
====================================

상단 요약 카드 4개:
1. 내 현장 수 (프로젝트 총 N개)
2. 평균 리스크 점수 (전체 프로젝트 평균, 등급 색상)
3. 법령 미충족 현장 (미충족 법령이 있는 프로젝트 수)
4. 하자담보 만료 임박 (30일 이내 만료 하자담보 수)

중단:
프로젝트 카드 그리드:
- 각 카드: 현장명, 업종 아이콘, 리스크 게이지(소형), 공정률 바
- 리스크 등급 배지 (안심/주의/경고/위험)
- 법령 미충족 N건 배지 (빨간색)
- 소방 미충족 시 🔥 배지
- 카드 클릭 → /projects/:id

하단:
- 긴급 이슈 리스트:
  - 소방 미충족 (최상단 — 인명 관련)
  - 법령 위반
  - 하자담보 만료 임박
  - 리스크 위험 등급 프로젝트
- 각 이슈 클릭 → 해당 프로젝트 해당 탭으로 이동

프로젝트 0개일 때:
- 온보딩 화면: "체크인에 오신 것을 환영합니다" + "첫 현장을 등록하세요" 버튼 + 간단한 3단계 설명

====================================
B. 증거 패키지 PDF 기본 생성
====================================

프로젝트 상세 페이지에 "증거 패키지 다운로드" 버튼 추가.
클릭 시 브라우저에서 PDF 생성 (react-pdf, html2canvas+jsPDF, 또는 서버사이드 puppeteer 중 가능한 방식):

PDF 내용:
1. 표지
   - 체크인 로고
   - 프로젝트명
   - 기간 (시작일 ~ 종료일)
   - 생성일
   - "본 문서는 체크인 시스템에 의해 자동 생성되었습니다."

2. 리스크 요약 (1페이지)
   - 최종 리스크 점수 + 등급
   - 법령 준수 현황 요약 (17개 법령 상태)
   - 체크리스트 완료율

3. 법령 체크 결과 (1~2페이지)
   - 17개 법령 각각: 법령명, 조문, 상태, 판정 근거

4. 사진 증거 (페이지당 2장)
   - 법정 증거 지정된 사진만
   - 각 사진: 이미지 + 촬영일시 + GPS + SHA-256 해시값

5. 무결성 정보 (마지막 페이지)
   - Merkle Tree 루트 해시
   - 포함된 증거 사진 수
   - "본 증거 패키지의 무결성은 SHA-256 해시 및 Merkle Tree로 보장됩니다."

디자인 안 예뻐도 된다. 내용이 전부 들어가는 게 우선.
PDF가 기술적으로 어려우면 HTML 페이지로 먼저 만들고 브라우저 인쇄(Ctrl+P)로 PDF 저장하는 방식도 OK.

====================================
C. 전체 사용자 여정 점검
====================================

아래 시나리오를 처음부터 끝까지 실행하고, 막히는 곳이 있으면 수정:

1. /login 접속 → 로그인 (테스트 모드)
2. /dashboard → 빈 상태 화면 확인
3. "첫 현장 등록" 클릭 → /projects/new
4. 현장 정보 입력 (카페 인테리어, 강남, 5천만원, 3개월)
5. 등록 → /projects/:id로 이동
6. 개요 탭: 리스크 점수 초기값 확인
7. 체크리스트 탭: 자동 생성된 체크리스트 확인, 일부 항목 체크
8. 체크 후 개요 탭: 리스크 점수 변동 확인
9. 사진/증거 탭: 사진 3장 업로드
10. 업로드 후: SHA-256 해시 생성 확인
11. 사진 1장 법정 증거 지정
12. Merkle Tree 생성
13. 법령 현황 탭: 17개 법령 상태 확인
14. 소방 안전 탭: 소방 점수 + NFSC 체크리스트 확인
15. 하자담보 탭: "공사 완료 처리" → 하자담보 자동 생성 확인
16. 증거 패키지 다운로드 (PDF 또는 HTML)
17. /dashboard로 돌아가기: 프로젝트 카드에 리스크 점수 반영 확인

16단계 중 막히는 곳이 있으면 해당 단계의 코드를 수정해서 통과시켜.
전체 통과되면 완료.

- docs/BUSINESS_LOGIC.md에 변경사항 반영
```
