# docs 폴더 정리 + 소방 NFSC 실행

> 이 프롬프트를 먼저 실행해서 docs 폴더를 정리한 후, 소방 작업을 진행한다.

---

## 프롬프트: docs 폴더 정리 + 소방 NFSC 실행

```
docs/ 폴더를 정리하고, 소방 체크리스트를 NFSC 기반으로 전면 교체해줘.

====================================
작업 1: docs 폴더 구조 정리
====================================

현재 docs/ 폴더에 설계 문서와 프롬프트 파일이 섞여 있다.
아래 구조로 정리해줘:

docs/
├── ARCHITECTURE.md          ← 현행 설계 (절대 삭제 금지)
├── SCHEMA.md                ← 현행 설계 (절대 삭제 금지)
├── BUILDER_SPEC.md          ← 현행 설계 (절대 삭제 금지)
├── BUSINESS_LOGIC.md        ← 현행 설계 (절대 삭제 금지)
├── API_SPEC.md              ← 현행 설계 (절대 삭제 금지)
├── prompts/                 ← 실행용 프롬프트 (참고용, 설계 아님)
│   ├── completed/           ← 실행 완료된 프롬프트
│   └── pending/             ← 아직 실행 안 한 프롬프트
└── archive/                 ← 대체/폐기된 파일

이동 규칙:
- 한글 파일명의 .md 파일들은 전부 프롬프트다. docs/ 루트에서 prompts/ 하위로 이동.
- 이미 실행 완료된 프롬프트 → prompts/completed/로 이동:
  - 체크인_랜딩페이지_개선_프롬프트_5종.md (실행 완료)
  - 체크인_랜딩페이지_보완_2차_프롬프트_5종.md (실행 완료)
  - 체크인_30종_문서체계_생성_프롬프트.md (대체됨 → archive/로)
  - 체크인_30종_문서체계_통합_프롬프트.md (대체됨 → archive/로)
  - 체크인_핵심엔진_구현_프롬프트_5종.md (대체됨 → archive/로)

- 아직 실행 안 했거나 실행 중인 프롬프트 → prompts/pending/로 이동:
  - 체크인_핵심업데이트_통합_프롬프트.md (실행 중이면 completed/로)
  - 체크인_소방_특별모듈_프롬프트.md (실행 중이면 completed/로)

- 대체된 파일 → archive/로 이동:
  - 체크인_소방_체크리스트_구조수정.md (NFSC 버전으로 대체됨)

- 체크인_소방_NFSC_전체반영.md → prompts/pending/로 이동

핵심 규칙:
- docs/ 루트에는 영문 설계 문서만 존재해야 한다.
- 프롬프트 파일은 설계 문서가 아니다. Claude Code가 코드 작업할 때 참조하는 것은 docs/ 루트의 설계 문서뿐이다.
- prompts/ 폴더는 사람이 Claude Code에게 지시할 때 사용하는 파일이지, Claude Code가 자동으로 읽는 파일이 아니다.

====================================
작업 2: 소방 NFSC 기반 체크리스트 전면 교체
====================================

docs/prompts/pending/체크인_소방_NFSC_전체반영.md를 읽고 실행해줘.

요약:
- 기존 감으로 만든 소방 체크리스트를 전부 삭제
- NFSC(화재안전기준) 조문 번호 기반으로 재생성
- 구조: 공통 필수(약 70~80개) + 업종별 추가
- 각 항목에 legal_basis 필드로 법적 근거 명시 (예: "NFSC 101 제4조")
- checklist_items 테이블에 legal_basis 컬럼 없으면 추가
- 소방 전용 페이지에서 NFSC 기준별 그룹핑 표시
- 법령 체크 서비스와 연동

상세 내용은 해당 파일에 전부 있으니 그대로 따라.

====================================
작업 3: 설계 문서 업데이트
====================================

작업 1, 2 완료 후:
- docs/SCHEMA.md: checklist_items 테이블에 legal_basis 컬럼 추가 반영
- docs/BUILDER_SPEC.md: 소방 체크리스트 "NFSC 기반, 공통 70~80개 + 업종별 추가" 명시
- docs/BUSINESS_LOGIC.md: 소방 법령 판정 로직에 NFSC 카테고리별 매핑 추가
- 각 문서 상단 "최종 업데이트" 날짜를 오늘로 변경

====================================
주의사항
====================================

- docs/ 루트의 영문 설계 문서 5개는 절대 삭제하지 마. 이게 프로젝트의 정본이다.
- 프롬프트 파일을 설계 문서로 착각하지 마. 프롬프트는 "지시서"이고 설계 문서는 "설계도"다.
- 코드 작업 시 참조할 문서는 docs/ 루트의 설계 문서뿐이다.
```
