# 체크인 랜딩페이지 개선 프롬프트 5종

> 순서대로 1번부터 하나씩 Claude Code에 입력할 것. 1번 완료 확인 후 2번 진행.

---

## 프롬프트 1: 상단 네비게이션 바 추가

랜딩페이지(localhost:3005) 최상단에 고정 네비게이션 바를 추가해줘.

구성:
- 왼쪽: 체크인 로고 (현재 히어로에 있는 것과 동일한 스타일)
- 가운데: 메뉴 링크 4개 — "기능", "법령", "요금제", "FAQ" (각각 해당 섹션으로 스크롤 이동하는 앵커 링크)
- 오른쪽: "로그인" 텍스트 버튼 + "무료 시작" 주황색 버튼 (로그인은 /login으로, 무료 시작도 /login으로 이동)

스타일:
- 배경: 다크 (#1a1a2e 또는 현재 히어로 배경색과 동일), 스크롤 시 약간 blur 효과
- position: fixed, top: 0, z-index: 50, width: 100%
- 텍스트: 흰색, hover 시 주황색(#E8913A)
- 높이: 64px
- 스크롤 내려가면 배경에 backdrop-blur + 약간의 투명도 추가

네비게이션 바 높이만큼 히어로 섹션 상단에 padding-top 추가해서 내용이 가려지지 않게 해줘.

## 프롬프트 2: 텍스트 가독성 미세 조정

랜딩페이지에서 아직 가독성이 약한 텍스트들을 수정해줘.

1. 히어로 섹션
- "데모 보기 ▶" 버튼 텍스트를 #FFFFFF 흰색으로 변경, 버튼에 border: 1px solid rgba(255,255,255,0.3) 추가
- 하단 신뢰 배지 "특허 3건 등록", "법령 12개 자동", "분쟁 예방 보장" 텍스트를 rgba(255,255,255,0.9) 이상으로 밝게

2. 12개 법령 자동 적용 섹션
- 법령 카드 안의 설명 텍스트 (예: "제28조 하자담보책임", "수급인의 담보책임" 등)를 rgba(255,255,255,0.8) 이상으로 밝게
- 카드 번호(01, 02 등)도 현재보다 밝게 rgba(255,255,255,0.5) → rgba(255,255,255,0.7)

3. 로그인 페이지
- "회원가입" 비활성 탭 텍스트를 현재보다 밝게 — rgba(255,255,255,0.6) 이상으로 설정
- 비활성 탭도 클릭 가능하다는 게 보여야 함

모든 변경은 기존 디자인 톤을 유지하면서, 텍스트만 더 잘 보이게 하는 것. 색상 체계를 바꾸지 마.

## 프롬프트 3: 요금제 카드 디자인 통일 + CTA 강화

랜딩페이지 요금제 섹션을 다듬어줘.

1. 카드 디자인 통일
- Free, Starter, Enterprise 카드 배경을 현재 흰색에서 다크 계열(#1e293b 또는 #2a2a3e)로 변경
- 텍스트는 흰색, 가격은 주황색(#E8913A) 유지
- Pro 카드는 현재 강조 스타일 유지하되, 테두리를 주황색 glow로: border: 2px solid #E8913A, box-shadow: 0 0 20px rgba(232,145,58,0.3)
- "가장 인기" 배지는 현재 그대로 유지

2. 버튼 스타일 통일
- Free: "무료 시작" 버튼 → 테두리만 있는 스타일 (border: 1px solid rgba(255,255,255,0.3), 배경 투명)
- Starter: "14일 무료체험" → 같은 테두리 스타일
- Pro: "14일 무료체험" → 주황색 배경 (#E8913A), 흰 텍스트, 가장 눈에 띄게
- Enterprise: "상담 신청" → 테두리 스타일

3. 하단 CTA "지금 바로 무료로 시작하세요" 영역
- "무료로 시작하기 →" 버튼을 주황색 배경(#E8913A) + 흰 텍스트로 변경 (현재는 흰 배경에 주황 텍스트라 약하다)
- 버튼 크기도 좀 더 키워줘 (padding 늘리기)

## 프롬프트 4: 푸터 추가

랜딩페이지 최하단에 푸터를 추가해줘.

구성 (3컬럼 + 하단 카피라이트):
- 왼쪽 컬럼: 체크인 로고 + 한 줄 설명 "AI 기반 건설 분쟁 예방 플랫폼" + 이메일 "contact@check-in.kr"
- 가운데 컬럼: "서비스" 제목 아래 링크 — 기능 소개, 요금제, 법령 안내, FAQ
- 오른쪽 컬럼: "법적 고지" 제목 아래 링크 — 이용약관, 개인정보처리방침, 사업자 정보

하단 구분선 아래:
- "© 2025 체크인. All rights reserved." 왼쪽 정렬
- 오른쪽에 "특허 출원번호: 10-2024-XXXXXXX" (실제 번호 있으면 넣고 없으면 이 형식으로 placeholder)

스타일:
- 배경: 현재 페이지에서 가장 어두운 색 (#0f0f1a 또는 유사)
- 텍스트: rgba(255,255,255,0.6), 링크 hover 시 흰색
- 상단 구분선: 1px solid rgba(255,255,255,0.1)
- padding: 상하 60px

링크들은 아직 실제 페이지가 없으니 href="#"으로 처리해둬.

## 프롬프트 5: 모바일 반응형 대응

랜딩페이지 전체를 모바일(375px ~ 768px)에서도 제대로 보이게 반응형 처리해줘.

1. 히어로 섹션
- 좌측 텍스트 + 우측 대시보드 카드 → 모바일에서는 세로 배치 (텍스트 위, 카드 아래)
- 대시보드 미리보기 카드 width: 100%, 좌우 padding 16px
- 메인 카피 폰트 사이즈 축소 (데스크탑 대비 60~70%)

2. 3가지 실수 카드 섹션
- 3열 → 모바일에서 1열 세로 배치

3. 4가지 핵심 기능 카드
- 4열 → 모바일에서 2열 또는 1열

4. 12개 법령 카드
- 4열x3행 → 모바일에서 2열x6행 또는 1열

5. 요금제 카드
- 4열 → 모바일에서 1열 세로 배치, 좌우 스와이프 또는 세로 스크롤

6. 네비게이션 바 (프롬프트 1에서 추가한 것)
- 모바일에서 가운데 메뉴 숨기고 햄버거 아이콘으로 대체
- 햄버거 클릭 시 전체 화면 또는 드롭다운 메뉴

7. 푸터
- 3컬럼 → 모바일에서 1컬럼 세로 배치

전체적으로 모바일에서 좌우 패딩 16~20px 유지하고, 텍스트가 잘리거나 넘치지 않게 해줘. Tailwind breakpoint 기준으로 sm: md: lg: 활용해서 처리해줘.
