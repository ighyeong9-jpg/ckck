# 체크인 소방 특별 모듈 구현 프롬프트

> 소방은 "분쟁 예방"이 아니라 "생명 보호"다. 다른 법령과 무게가 다르다.
> 12개 법령 → 소방 5개 추가하여 17개로 확장 + 소방 전용 페이지 신설 + 소방 전용 체크리스트
> 프롬프트 1 → 2 → 3 순서. 완료 확인 후 다음 진행.

---

### 작업 2: law_checks 서비스에 소방 판정 로직 추가

기존 법령 체크 서비스(checkSingleLaw 함수)에 새 타입 추가:

"fire_checklist_check":
→ checklists 테이블에서 target_category에 해당하는 체크리스트 조회
→ completion_rate가 min_completion% 이상이면 compliant, 미만이면 violated
→ 해당 카테고리 체크리스트 없으면 violated (소방은 없는 것 자체가 위반)
→ 주의: 다른 법령은 체크리스트 없으면 not_applicable이지만, 소방은 없으면 violated

"compound_check":
→ required_categories 각각의 체크리스트 완료율 확인
→ 전부 min_completion% 이상이면 compliant
→ 하나라도 미달이면 violated
→ 하나라도 체크리스트가 없으면 violated

"multi_use_check":
→ 프로젝트 type이 applicable_types에 포함되는지 먼저 확인
→ 미포함이면 not_applicable
→ 포함이면 target_category 체크리스트 완료율 확인
→ min_completion% 미만이면 violated

### 작업 3: 리스크 점수의 Fp 계산에 소방 반영

소방 법령(category='fire_safety')은 risk_weight가 1.3~1.5로 다른 법령(0.7~1.2)보다 높다.
Fp 계산 시 가중 평균이므로 소방 위반 시 리스크 점수가 크게 올라간다.
이 부분이 기존 calculateRiskScore에서 자동으로 반영되는지 확인하고, 안 되면 수정.

### 체크리스트 DB 시딩 방법

기존 체크리스트 생성 방식을 확인하고, 같은 패턴으로 소방 체크리스트를 시드 데이터에 추가.
프로젝트 생성 시 업종(type) 선택에 따라 해당 소방 체크리스트가 자동으로 포함되게.

기존 체크리스트 자동 생성 로직에서:
- 프로젝트 type이 cafe면 → A(카페/식당) 소방 체크리스트 자동 추가
- residential이면 → B(주거용) 추가
- commercial/office면 → C(상업시설) 추가
- factory면 → D(공장/창고) 추가

### 소방 체크리스트 특수 규칙

1. 소방 체크리스트는 is_required = true (전항목 필수)
2. 소방 체크리스트 미완료 시 해당 법령이 자동으로 violated 처리
3. 소방 체크리스트에는 반드시 사진 증거 연결을 권장하는 안내 표시
   - 각 항목 옆에 "📷 사진 촬영 권장" 아이콘
   - 사진 없이 체크하면 "사진 증거 없이 체크되었습니다. 증빙력이 약할 수 있습니다." 경고

완료 후 docs/BUILDER_SPEC.md의 체크리스트 모듈에 소방 체크리스트 내용 추가.
```

```

====================================

====================================

### 상단: 소방 안전 종합 현황

배경: 다크 레드 계열 그라데이션 — 다른 페이지와 시각적 차별화
아이콘: 🔥 또는 소방 관련 아이콘

소방 안전 점수 (원형 게이지):
- 소방 관련 5개 법령의 충족률 기반 점수 (0~100)
- 계산: (compliant 법령 수 / 적용 대상 법령 수) × 100
- 색상: 80 이상 초록, 60~79 주황, 60 미만 빨강

요약 카드 3개:
1. "소방 법령 충족" — 5개 중 N개 충족 / N개 미충족
2. "소방 체크리스트" — 전체 N개 항목 중 N개 완료 (N%)
3. "소방 증빙 사진" — N장 촬영, N장 미촬영

### 중단: 소방 법령 5개 상세

5개 법령 각각을 카드로 표시:

카드 구성:
- 법령명 + 조문
- 상태: ✅ 충족 / ⚠️ 미충족 / ➖ 해당없음
- 미충족 시 구체적 사유 (details JSON에서 추출)
- 권장 조치 (violation_action)
- "관련 체크리스트 보기" 버튼 → 해당 체크리스트로 이동

카드 순서:
1. 소방시설법 (스프링클러, 소화기 등)
2. 화재예방법 (공사 중 화기 관리)
3. 중대재해처벌법 (형사처벌 — 빨간 강조)
4. 건축법 방화구획 (방화문, 피난시설)
5. 다중이용업소법 (소방완비증명서)

중대재해처벌법 카드는 특별 강조:
- 배경: 빨간 테두리 또는 빨간 배지
- "⚖️ 형사처벌 대상 — 사업주 1년 이상 징역 또는 10억 이하 벌금"
- 미충족 시 가장 눈에 띄게

### 하단 좌측: 소방 체크리스트

카테고리별 탭:
- 소방시설 (fire_facility)
- 화재예방 (fire_prevention)
- 방화/피난 (fire_escape)
- 소방완비증명 (fire_certificate) — 다중이용업소만 표시

각 카테고리별:
- 체크 항목 리스트 (체크박스)
- 각 항목 옆에 📷 사진 연결 버튼
- 사진 없이 체크 시 "증빙 사진 없음" 노란 경고
- 카테고리별 완료율 프로그레스 바

### 하단 우측: 소방완비증명서 발급 가이드

접이식(아코디언) 가이드:

Step 1: 소방시설 설치
- "프로젝트 유형에 맞는 소방시설을 설치하세요."
- 체크리스트의 fire_facility 카테고리 완료율 표시
- 미완료 항목 하이라이트

Step 2: 소방시설 완공 검사 신청
- "관할 소방서에 완공 검사를 신청하세요."
- 필요 서류: 소방시설 설치 신고서, 도면, 시공 사진
- "체크인에서 증빙 패키지를 생성하면 필요 서류를 자동으로 정리할 수 있습니다."

Step 3: 현장 점검
- "소방서 직원이 현장을 방문하여 점검합니다."
- 주요 점검 항목 리스트 (체크리스트와 연동)

Step 4: 소방완비증명서 발급
- "점검 통과 시 소방완비증명서가 발급됩니다."
- "다중이용업소는 이 증명서 없이 영업 신고 불가"

Step 5: 정기 점검
- "발급 후에도 정기 점검 의무가 있습니다."
- "체크인이 점검 주기를 자동으로 알려드립니다." (알림 연동 예고)
