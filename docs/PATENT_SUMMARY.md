# Check-In 특허 요약

## 특허 3건 등록 확정

### 특허 1: AI 기반 건설 리스크 예측 시스템
- **출원번호**: 대한민국 특허 출원
- **핵심 청구항**: R = Fp×Wf + Oc×Wo + Ch×Wc 공식을 이용한 건설 프로젝트 리스크 자동 계산 방법
- **차별점**: 재정·발생빈도·변경영향 3축 복합 분석
- **적용**: 대시보드 리스크 점수, AI 브리핑

### 특허 2: 블록체인 기반 건설 증빙 무결성 시스템
- **핵심 청구항**: SHA-256 Merkle Tree를 이용한 건설 현장 증빙 자료의 무결성 검증 방법
- **차별점**: 오프체인 저장 + 온체인 해시로 비용 절감
- **적용**: 증빙 패키지, AI 인증서

### 특허 3: 건설 현장 4단계 안전 현황 시스템
- **핵심 청구항**: 체크리스트 이행률 기반 4단계(안전/주의/경고/위험) 자동 판정 및 색상 시각화 방법
- **차별점**: 12개 법규 기반 자동 판정
- **적용**: 안전 현황 배지, 대시보드 4단계 표시

## 지식재산권 전략
- 국내 특허 3건 → PCT 국제출원 예정
- 상표: "체키" 국내 상표 등록 완료
- 디자인: 4단계 색상 시스템 디자인 등록
