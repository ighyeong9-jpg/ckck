# Check-In 사용자 가이드 (역할별)

> **제품명**: Check-In (기록의 편) — 건설·인테리어 프로젝트 리스크 및 책임 기록 플랫폼

---

## 1. 공통 안내

### 접속 및 메뉴

- **홈** `/` → 로그인·회원가입
- **로그인** `/login` · **회원가입** `/signup` → 이메일/비밀번호 (Supabase Auth)
- **대시보드** `/dashboard` → 전체/진행중/완료 프로젝트 수
- **프로젝트** `/projects` → 프로젝트 목록, 카드 클릭 시 상세

프로젝트 상세 내 탭:

| 탭 | 경로 | 설명 |
|----|------|------|
| 사전점검 | `/projects/[id]/precheck` | 현장 사전점검 체크리스트 |
| 변경사항 | `/projects/[id]/changes` | 변경 요청·승인 내역 |
| 하자관리 | `/projects/[id]/defects` | 하자 등록·처리 현황 |

시스템 역할: `admin`, `contractor`, `client` (타입 정의 기준).

---

## 2. 역할별 가이드

### 2.1 현장소장

- **역할**: 현장 총괄, 진행·리스크·변경·하자 최종 확인. **권한**: admin 또는 contractor 권한 사용.
- **이용 흐름**: 대시보드 → 프로젝트 선택 → 상세(발주처, 금액, 주소, 일정, 진행률) 확인 → 사전점검(완료율·항목 체크·사진) → 변경사항(건수, 승인대기, 금액 증가, + 변경 요청) → 하자관리(전체/미해결/처리율, + 하자 등록). 기록은 기록 관리 시 책임 소재 확인용으로 활용.

### 2.2 안전관리자

- **역할**: 안전 점검·사전점검(특히 안전 항목)·안전 관련 하자 관리. **권한**: contractor.
- **이용 흐름**: 프로젝트 선택 → 사전점검에서 안전 카테고리 우선 점검·체크·사진 → 하자관리에서 안전 관련 하자 등록(심각도·위치·설명) → 변경사항에서 안전 관련 변경 확인.

### 2.3 작업반장

- **역할**: 일일 작업·사전점검 실행·하자·변경 최초 보고. **권한**: contractor.
- **이용 흐름**: 프로젝트 선택 → 사전점검(작업 전·중 점검 체크·메모·사진) → 하자 등록(+ 하자 등록) → 변경 필요 시 + 변경 요청 → 프로젝트 상세 최근 활동에서 반영 확인.

### 2.4 일반작업자

- **역할**: 현장 작업·점검·하자 발견 시 보고. **권한**: contractor 또는 제한 조회.
- **이용 흐름**: 배정된 프로젝트 → 사전점검(담당 항목 체크·날짜) → 하자 발견 시 + 하자 등록 또는 반장/안전관리자에게 전달·사진 증빙.

### 2.5 감리

- **역할**: 품질·진도·변경·하자 검토·승인. **권한**: admin 또는 감리 전용(도입 시).
- **이용 흐름**: 대시보드·프로젝트로 감리 대상 확인 → 사전점검 검토·보완 요청 → 변경사항에서 승인대기 검토·승인/거부 → 하자관리에서 처리 상태 검토·조치 요청 → 프로젝트 상세에서 리스크·책임 구간 파악.

### 2.6 하도급

- **역할**: 하도급 구간 시공·점검·하자·변경 기록. **권한**: contractor(해당 프로젝트).
- **이용 흐름**: 참여 프로젝트 선택 → 사전점검(하도급 공종 항목·증빙) → 변경사항(+ 변경 요청, 금액·사유)·승인 상태 확인 → 하자관리(자신 공종 하자 등록·상태 협의).

### 2.7 건축주

- **역할**: 발주자 관점 진행·변경·하자 확인. **권한**: client.
- **이용 흐름**: 대시보드 → 프로젝트 상세(금액·일정·진행률·최근 활동) → 변경사항(건수·금액 증가·승인 여부) → 하자관리(건수·미해결·처리율·내용) → 사전점검 참고 확인. 기록 관리·하자보수 대비 기록 확인.

### 2.8 건물관리자

- **역할**: 시설물 측에서 현장·안전·변경·하자 확인·동의. **권한**: client 또는 건물관리자(도입 시).
- **이용 흐름**: 해당 시설물 프로젝트 선택 → 사전점검(공용부·안전 항목) → 변경사항(공용부·시설 변경 여부) → 하자관리(공용부·시설 관련 하자) → 프로젝트 상세(일정·진행률).

---

## 3. 상태·용어

- **프로젝트**: 계획 / 진단 / 진행중 / 완료 / 기록 관리  
- **변경**: 승인대기 / 승인 / 거부  
- **하자**: 미해결 / 처리중 / 완료 · 심각도: 긴급 / 높음 / 보통 / 낮음  

기능·권한은 배포 환경과 운영 정책에 따라 다를 수 있습니다. (문서만 작성, 코드 수정 없음.)
